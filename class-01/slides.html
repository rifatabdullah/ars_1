How computers see

00–20 min

To a computer, a photo is just a big table of numbers.

An image is a grid of pixels

Each square is one pixel. Each pixel is one number:

  • 0 = black
  • 255 = white
  • anything between = a shade of grey

Hover a pixel:

img[row, col] = …

Grayscale = a 2D matrix

import numpy as np

img = np.array([[  0,  50, 100],
                [150, 200, 255]],
               dtype=np.uint8)

img.shape     # (2, 3) → 2 rows (height), 3 cols (width)
img.dtype     # uint8 → whole numbers 0…255
img[1, 2]     # 255   → row 1, column 2
img.max()     # 255

Remember

  • Shape is (height, width): rows first
  • Index is img[y, x], starting at 0
  • uint8 = 8 bits = 2⁸ = 256 values
  • A 1080p photo = 1080 × 1920 ≈ 2 million numbers

Colour = a 3D array (3 layers)

Each colour pixel has 3 numbers: how much red, green and blue light.

img.shape   # (height, width, 3)
img[y, x]   # → [B, G, R]  three numbers

⚠️ OpenCV stores colours as BGR, not RGB! Matplotlib expects RGB, so un-converted photos look blue-ish. Fix: cv2.cvtColor(img, cv2.COLOR_BGR2RGB)

Make an image from scratch

import numpy as np
import cv2

canvas = np.zeros((200, 300, 3), dtype=np.uint8)  # all black

canvas[:, :] = (255, 0, 0)          # all BLUE (BGR!)
canvas[50:150, 100:200] = (0, 255, 255)  # yellow box

cv2.circle(canvas, (150, 100), 30, (0, 0, 255), -1)  # red dot

Try it in Colab

Change the numbers and re-run. What colour is (0, 255, 0)? What about (255, 255, 255)?

Note: drawing functions take points as (x, y) but array indexing is [y, x].

Basic transformations

20–45 min

Load, show, convert, resize, rotate and crop.

Loading & showing in Colab

import cv2, numpy as np, matplotlib.pyplot as plt
from google.colab import files
from google.colab.patches import cv2_imshow   # cv2.imshow() does NOT work in Colab

uploaded = files.upload()                  # opens a "Choose file" button
path = list(uploaded)[0]

img = cv2.imread(path)                     # → NumPy array, BGR order
print(img.shape, img.dtype)               # e.g. (720, 1280, 3) uint8

cv2_imshow(img)                            # option 1: quick look
plt.imshow(cv2.cvtColor(img, cv2.COLOR_BGR2RGB)); plt.axis("off")  # option 2

If cv2.imread returns None, the path is wrong. Check the 📁 Files panel on the left.

Converting colour spaces 🎨

gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)  # (h, w)
rgb  = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)   # for plt
hsv  = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)   # hue/sat/value

print(img.shape)    # (720, 1280, 3)
print(gray.shape)   # (720, 1280)  ← one layer!

plt.imshow(gray, cmap="gray")

How is grey computed?

A weighted mix: our eyes are most sensitive to green.

Y = 0.299·R + 0.587·G + 0.114·B

Forgetting cmap="gray" in Matplotlib gives a weird yellow-purple image.

Resizing 📏

# exact size — NOTE: (width, height) order!
small = cv2.resize(img, (320, 240))

# scale by a factor (keeps proportions)
half = cv2.resize(img, None, fx=0.5, fy=0.5)

# keep aspect ratio for a target width
h, w = img.shape[:2]
new_w = 400
new_h = int(h * new_w / w)
fit = cv2.resize(img, (new_w, new_h),
                 interpolation=cv2.INTER_AREA)

Gotchas

  • img.shape → (h, w) but cv2.resize wants (w, h)
  • Shrinking? use INTER_AREA
  • Enlarging? use INTER_LINEAR or INTER_CUBIC
  • Forcing a new shape squashes or stretches the photo

Rotating 🔄 — matrices are back!

# quick 90° turns and flips
r90  = cv2.rotate(img, cv2.ROTATE_90_CLOCKWISE)
flip = cv2.flip(img, 1)          # 1 = left↔right, 0 = up↕down

# any angle: build a 2×3 transformation MATRIX
h, w = img.shape[:2]
center = (w // 2, h // 2)
M = cv2.getRotationMatrix2D(center, 30, 1.0)  # 30°, scale 1
print(M)
rot = cv2.warpAffine(img, M, (w, h))

What's inside M?

The rotation matrix, plus a column that shifts the picture so it spins around the centre:

[[ cos θ, sin θ, tx ],
 [ −sin θ, cos θ, ty ]]

OpenCV multiplies every pixel's (x, y) by this matrix to find where it lands.

Cropping = array slicing ✂️

Drag on the picture to choose a region of interest (ROI).

roi = img[y1:y2, x1:x2]

No copying, no special function: just [rows, columns]. Use roi.copy() if you'll change it.

Image enhancement & edges

45–75 min

Clean up noise, simplify to black & white, and find outlines.

Gaussian blur: smoothing noise 🌫️

Replace each pixel with a weighted average of its neighbours. Pixels near the centre count most.

121242121
 ÷ 16 (a 3×3 Gaussian kernel) 
blur = cv2.GaussianBlur(gray, (5, 5), 0)
#                    kernel size ↑    ↑ sigma (0 = auto)

Rules of thumb

  • Kernel size must be odd: 3, 5, 7…
  • Bigger kernel = smoother but blurrier
  • Random speckles ("noise") cause fake edges, so blur before edge detection

Binary thresholding ⚫⚪

Pick a cut-off T. Every pixel becomes pure black or pure white:

pixel > T → 255   else → 0

T, bw = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)

# let OpenCV choose T automatically (Otsu)
T, bw = cv2.threshold(blur, 0, 255,
                      cv2.THRESH_BINARY + cv2.THRESH_OTSU)
print("Otsu picked", T)

In one line of NumPy

bw = np.where(gray > 127, 255, 0)

Used for: scanning documents, reading signs, separating an object from its background.

THRESH_BINARY_INV flips it: dark things become white.

Canny edge detector ✏️

Grayscale→ Blur→ Gradients
how fast brightness changes→ Thin edges
keep only the peak→ Two thresholds
low & high 
gray  = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
blur  = cv2.GaussianBlur(gray, (5, 5), 0)
edges = cv2.Canny(blur, 50, 150)   # low, high

The two thresholds

  • Stronger than high → definitely an edge
  • Weaker than low → thrown away
  • In between → kept only if touching a strong edge

Tip: start with high ≈ 3 × low.

In-class lab: Photo → Edge sketch

75–90 min

Put everything together in one script.

Lab: your mission 🎯

  1. Load a photo (upload your own, or use the sample)
  2. Crop the main subject with slicing img[y1:y2, x1:x2]
  3. Convert to grayscale
  4. Blur to remove noise
  5. Run Canny to find the outlines
  6. Invert so lines are black on white: 255 - edges
  7. Show original vs. sketch side by side, and save it

Notebook: class-01/colab/lab01_edge_sketch.ipynb. Upload it to Colab (File → Upload notebook).

Lab: skeleton code

img  = cv2.imread("photo.jpg")
h, w = img.shape[:2]

roi    = img[int(h*.1):int(h*.9), int(w*.2):int(w*.8)]   # TODO: tune for your subject
gray   = cv2.cvtColor(roi, cv2.COLOR_BGR2GRAY)
blur   = cv2.GaussianBlur(gray, (5, 5), 0)
edges  = cv2.Canny(blur, 50, 150)
sketch = 255 - edges                                 # black lines, white paper

cv2.imwrite("sketch.png", sketch)
files.download("sketch.png")

🌟 Make it cleaner

Too many tiny lines? Blur more (7×7, 9×9) or raise the thresholds.

🌟🌟 Thicker lines

edges = cv2.dilate(edges, np.ones((2, 2), np.uint8))
