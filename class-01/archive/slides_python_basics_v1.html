Why a virtual environment?

Imagine every project shares one big toy box. Project A needs Lego v1, project B needs Lego v2… 💥 chaos!

A virtual environment (venv) gives each project its own little box.

WorkShop Class/
├── .venv/            ← our private toolbox (Python + NumPy + Matplotlib)
├── requirements.txt  ← the shopping list of libraries
├── setup.sh          ← one command to build everything
└── class-01/
    ├── slides.html
    ├── examples/
    └── exercises/

Setting up, step by step

  1. Check Python is installed:
    python3 --version
  2. Create the environment:
    python3 -m venv .venv
  3. Switch it on (activate):
    source .venv/bin/activate        # Linux / macOS
.venv\Scripts\activate           # Windows
  4. Install the libraries:
    pip install -r requirements.txt

Shortcut: ./setup.sh does steps 2 & 4 for you.

Did it work? ✅

When the venv is active, your prompt shows (.venv) at the start:

(.venv) $ python -c "import numpy; print('NumPy is ready!')"
NumPy is ready!

Run your first program:

(.venv) $ python class-01/examples/01_hello.py

Finished for the day? Type deactivate to close the toolbox.

Remember lists — a matrix is just a list of lists!

Making decisions: if

temperature = 31

if temperature > 30:
    print("It's hot! 🥵")

    print("Nice weather 😎")

    print("Brr, cold! 🥶")

⚠️ The colon : and the indent (4 spaces) matter in Python!

Repeating things: loops 🔁

for — go through each item

for i in range(1, 6):
    print(i, "x 7 =", i * 7)

while — keep going until…

count = 3
while count > 0:
    print(count)
    count -= 1
print("Blast off! 🚀")

Matrix foundations

Grids of numbers with superpowers.

What is a matrix?

A matrix is a rectangle of numbers, arranged in rows and columns.

A = 123456 ← 2 rows, 3 columns: a 2 × 3 matrix

Where are matrices?

  • 📸 Every photo is a matrix of pixels
  • 🎮 Games use them to move & spin characters
  • 📊 Spreadsheets & seating charts

03_matrix_with_lists.pyA matrix in Python

A = [
    [1, 2],     # row 0
    [3, 4],     # row 1
]

print(A[0])       # [1, 2]   the whole first row
print(A[1][0])    # 3        row 1, column 0

Read it as A[row][column]. Both start counting at 0.

Adding & scaling matrices

Adding: add the numbers in the same spot.

1234 + 5678 = 681012

Scaling: multiply every number by the same amount.

10 × 1234 = 10203040

Multiplying matrices: row × column

Each answer = a row from the left matrix "dotted" with a column from the right.

1234 × 5678 = 19224350

Top-left: 1×5 + 2×7 = 5 + 14 = 19

⚠️ Order matters! A × B is not the same as B × A.

04_numpy_matrices.pyNumPy makes it easy

import numpy as np

A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

A.shape    # (2, 2)
A + B      # add
10 * A     # scale
A @ B      # matrix multiply  ← use @ !
A.T        # transpose: rows become columns
np.eye(2)  # identity matrix: the "do nothing" matrix

Careful: A * B multiplies number-by-number — that's different from A @ B.

4

Transformations

Using matrices to move shapes.

Points are tiny matrices

A point (x, y) can be written as a column:

p = xy

Multiply it by a 2×2 matrix and you get a new point:

abcd xy = a·x + b·yc·x + d·y

Do this to every corner of a shape, and the whole shape moves!

The transformation zoo 🦁

🔍 Scale

2002

Twice as big

🪞 Mirror

-1001

Flip left ↔ right

🔄 Rotate 90°

0-110

Quarter turn, anticlockwise

📐 Shear

1101

Slant like italics

Rotation by any angle

R(θ) = cos θ−sin θsin θcos θ 
import math
angle = math.radians(45)
R = np.array([[math.cos(angle), -math.sin(angle)],
              [math.sin(angle),  math.cos(angle)]])

Don't worry about why this works yet — just see what it does!

🎮 Matrix playground

Change the numbers and watch the house move. Grey = before, orange = after.

05_transformations.pyNow in Python

# each COLUMN is one corner of the house
house = np.array([[0, 2, 2, 1, 0, 0],    # x values
                  [0, 0, 2, 3, 2, 0]])   # y values

M = np.array([[0, -1],
              [1,  0]])          # rotate 90°

new_house = M @ house             # ← moves ALL corners at once!

plt.fill(*house, color="lightgray")
plt.fill(*new_house, color="orange")
plt.show()
python class-01/examples/05_transformations.py

Combining transformations ✨

Want to rotate and then scale? Multiply the matrices together!

combo = Scale @ Rotate        # read right-to-left: rotate first, then scale
new_house = combo @ house

This is exactly how video games move characters — thousands of times per second.
